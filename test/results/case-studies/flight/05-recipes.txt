# An empty heads file gives an empty --head. Since 0.1.4 that is a usage error (exit 2),
# not a silent skip. Shown as: tokening flight verify --db tokening.db --head "$(tail -n 1 heads.txt)"

$ tokening flight verify --db tokening.db --head ""
--head is empty. Give SEQ:HASH as printed by tokening flight head, or leave --head out. If it came from a file of saved heads, that file is empty or its last line is blank.
(exit 2)
